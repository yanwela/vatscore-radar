# Vatscore-radar
VatScore Web is a Streamlit-based global radar dashboard that fetches live flight and air traffic control (ATC) data from the VATSIM network to provide detailed airspace analytics.

## VatScore Strategic Development Roadmap

Our mission is to engineer the ultimate, high-fidelity data hub for the VATSIM network, focusing on premium telemetry and optimized interface layouts. Below is our active development queue.

### Phase 1: Telemetry and UI Expansion
- [x] Flight Detail Insight System: Implement interactive row-click actions on data tables to expand and view the full flight plan string (ROUTE), pilot real name, and voice VHF frequency metadata natively without leaving the view.

### Phase 2: Pro-Tier Filtering & Advanced Telemetry
- [x] Airline Call-Sign Isolation: Expand standard FIR filters to support global ICAO airline codes, allowing users to explicitly isolate specific fleets (e.g., THY, PGT, BAW).
- [x] Automated Telemetry Tagging "Flight Rules Box": Integrate automated IFR and VFR flight rule telemetry tags based on live flight plan data.
- [x] Real-Time Haversine Distance Engine: Replace estimated progress tracking with a precise coordinate calculation framework based on the Haversine Formula, cross-referencing live positions against global airport databases.
- [x] VIP Watchlist System: Allow seamless, persistent tracking of specific airframes and pilot CIDs across active radar sessions.
- [x] FIR Boundary Engine Overhaul: Replaced legacy prefix-only sector matching with a dual-mode Shapely geometry system. Aircraft are now validated against official VATSIM GeoJSON boundaries, with a dedicated physical airspace toggle for strict coordinate-based filtering.
- [x] Precision FIR Selectbox: Consolidated 200+ raw sector entries into a clean, country-level hub selector. All sub-sectors are merged under a single unified prefix, eliminating list clutter entirely.
- [x] JS Render Pipeline Fix: Resolved a critical data bypass where the JS engine was independently fetching unfiltered VATSIM data on every 30-second sync cycle, overriding all Python-side FIR and isolation filters.
- [x] Airframe Info Expansion: Telemetry Dossier upgraded with Registration and SELCAL fields parsed directly from pilot remarks, displayed in unified Type | Reg | SELCAL format. Online time reformatted to Min | Hour Min split for precise session tracking.
- [x] Airlines DB Client-Side Migration: Moved airline identity resolution from server-side Python fetch to browser-side async fetch, eliminating 403 access failures on restricted hosting environments.
- [ ] High-Availability Server Migration: Upgrade core network infrastructure to high-availability servers to support premium custom branding and stable user connections. ** IT HAS BEEN POSTPONED TO FUTURE PHASES! **

### Phase 3: The Ultimate Score, Analytics & Hyper-Personalization — Completed
Phase 3 delivers on the core promise of turning VatScore from a simple radar into a full performance analytics and scoring hub, anchored by a dedicated CID Intelligence page.
- [x] Dedicated CID Intelligence Hub: Replaced the old flat "CID Stats" tab with a fully independent statistics page, reachable via a seamless single-click native tab (no intermediate confirmation screen) and fully separate from the live radar's rendering pipeline.
- [x] Full-History statsim.net Integration: Engineered a chunked, parallelized fetch pipeline that works around statsim.net's 31-day query ceiling, pulling a pilot's entire flight and ATC history back to registration in seconds via concurrent windowed requests.
- [x] Time-Series Flight Statistics: Delivered dynamic monthly/yearly activity charts, ICAO airframe and manufacturer distribution breakdowns (Airbus, Boeing, etc.) with live filtering, and a longest-to-shortest flight ranking engine driven by independent hour and nautical-mile threshold sliders.
- [x] Route & Airline Intelligence: Added most-flown route detection, most-flown aircraft/airline identification cross-referenced against the VATSIM Radar airline registry, and a "most interesting route" algorithm that surfaces rare, long-haul flights instead of just the busiest ones.
- [x] ATC Sector Mastery Module: Introduced per-position ATC session analytics (All Time / This Year / This Month) with time-on-position ranking for any CID carrying a controlling history.
- [x] High-Level Profile Badges: Pilot, ATC, and military rating badges now decode VATSIM's real bitmask/tier tables directly, alongside registration date, division, and live-online status.
- [x] Real VHF Frequency Telemetry: Replaced the placeholder Voice/Text indicator with live COM frequency data sourced directly from VATSIM's official transceivers feed — the same approach used by VATSIM Radar.
- [x] Network-Wide Auto-Refresh Engine: Replaced a silently non-functional JS sync bridge with a proper scoped-fragment architecture — Leaderboard, Global Stats, Anomaly Radar, and the network counters now refresh live in the background every 20 seconds without disturbing in-progress input anywhere else on the page.
- [x] Rating Accuracy Overhaul: Corrected the ATC and pilot rating decoders to match VATSIM's official rating tables exactly, eliminating a long-standing off-by-one misclassification (e.g., a real S1 controller no longer reads as S2).
- [x] Security & Stability Hardening: Closed a stored-XSS vector in pilot-supplied name fields, fixed an app-wide crash on missing secrets configuration, and removed several dead/never-functional code paths inherited from earlier phases.
- [ ] Localized Favorites Ecosystem and the network-wide Leaderboard Ranking Badge (#xxxxx) are carried over to Phase 4 below — no reliable public data source exists yet for a true cross-network ranking, and favorites/local-storage pinning is being redesigned alongside the upcoming White Mode UI! **POSTPONED TO PHASE 4!**

### Phase 4: Live Operations, Persistent Infrastructure & Anomaly Intelligence — Completed
Phase 4 was the biggest single phase yet: new full-page views (Airport, Network Stats, Events), a live flight map with a real GPS track and airspace awareness, full Flight Replay and ATC Replay, account security hardening, a memory for the platform (GitHub-backed persistent storage), a rebuilt Anomaly Radar with its own long-term archive, and a data-quality pass across the board.
- [x] Security Hardening: Added admin login protection, request rate limiting, and closed stored-XSS vectors in pilot-supplied fields; tightened the Streamlit server configuration.
- [x] New Network Stats & Airport Pages: A Network Stats page breaking the whole network down by airport, airline, aircraft type, route, pilot, ATC and observer; a dedicated Airport page with a CID activity heatmap/map; assorted flight-window fixes and a shared-module refactor.
- [x] Live Flight Map: Replaced the static telemetry card with a live map showing the aircraft's real GPS track, FIR-crossing and approach-area overlays, and awareness of which controllers are working that flight.
- [x] Flight Replay & Global Stats Rebuild: Full flight replay inside CID Stats, and a rebuilt Global Stats tab.
- [x] ATC Replay, METAR, Region Picker & New Leaderboard: Replay of a controller's session, live METAR, an airspace-aware region/FIR picker that consolidated 200+ raw sector entries into clean country-level hubs, and a redesigned Leaderboard; also fixed pilot ratings sometimes showing as "Suspended" incorrectly.
- [x] Flight Record Map Controls: Added Follow and Fit route buttons to the live map inside Flight Record.
- [x] Admin Panel & Persistent Storage: Expanded the admin panel, fixed the browser tab title on hosted deploys, and gave the platform a memory — a private GitHub data repository now survives every redeploy and Streamlit Cloud restart, syncing the banner, blocklist, admin audit log and page-view logs automatically, with clear admin-panel status lines instead of silent failures.
- [x] Airport Ground Ops: Real taxiway/apron layouts (from OpenStreetMap) now render in ATC Replay and in a new live Airport tower map, with METAR shown on the Airport page and in the map popup.
- [x] Events Page & Event History Recording: A new Events page, plus persistent recording of every VATSIM event seen — the public feed only lists upcoming events, so the platform now keeps its own history the moment each one appears, the foundation for a future past-events stats page.
- [x] Flight Map Robustness: A guard against corrupt/glitchy position samples (the kind that used to draw a plane briefly teleporting or diving at -7,850 fpm), a rain radar (WXR) layer, and a distance-progress bar that now agrees with the live track.
- [x] Anomaly Radar Rebuilt: Severity reworked into High (emergency squawks, implausible speed/altitude), Medium (position/altitude jumps, frozen aircraft) and Low (duplicate connections, shared callsigns, GA-too-fast, slow-at-altitude); the last rule now uses each aircraft's real height above the nearest airport (AGL) from a 28,000-airport elevation index instead of one fixed altitude for the whole planet. The live table animates only where the data changed (a new row flashes once, a resolved one fades out once, counters tick on change), a 2-hour timeline chart shows the shape of recent activity, and a live map plots every open anomaly with a plane icon and a draggable tag.
- [x] Long-Term Anomaly Archive: A background recorder keeps watching the network even when nobody has the site open, writing closed anomalies to a persistent archive (detail events for 90 days, then rolled into hourly counts) with a History view — totals by type, an hourly distribution chart, and a "Near" column that names the actual region/country instead of a raw lat/lon pair.
- [x] FIR/Region Picker Overhaul: A region that spans several FIRs (Ankara and Istanbul inside Türkiye, the individual US ARTCCs, etc.) can now be narrowed to a single FIR's real airspace boundary; countries that use several airport-code prefixes (the US, Canada, Brazil, Russia and a dozen more) are merged into one region instead of listing each prefix separately, and China/Australia are single hubs the same way the US already was.
- [x] Aircraft Type Database Expansion: Replaced a hand-written ~14-manufacturer guess table with a 7,000+ row ICAO type-designator reference (manufacturer, model, category), fixing real misclassifications (a military C-17 no longer reads as a Cessna) and giving General Aviation/Helicopter categories real coverage instead of a couple dozen hardcoded types.
- [x] Selected FIR Focus Filters: Fleet-category and flight-rules filters now show which ones are active and how many aircraft they left, with a one-click reset; airlines are picked from a live, ranked list instead of typed ICAO codes; and every table/column/filter choice is remembered in the browser between visits.
- [x] "Most Interesting Route" Re-Algorithmed: The CID Stats highlight now scores a route by distance, how rarely it's been flown, whether it crosses a region/country border and whether the aircraft type is otherwise unique to that pilot — not just "the longest flight you've done exactly once."
- [x] Readable Rankings Charts: Leaderboard ranking charts show proper axis units and plain grouped numbers (40,000, not "40k"), with the Altitude ranking additionally showing flight levels (FL400) the way a pilot actually reads them.
- [x] Member Watchlist Redo: One editable table (a CID or callsign per row, with an optional note) replaces four separate text fields — a watched member is flagged whether they show up as a pilot or as a controller, appears on the live anomaly map, and a "just connected" alert now checks VATSIM's own login timestamp so it never falsely fires just because you opened the tab while they'd already been online for hours. Region pinning (favouriting a FIR/hub in Selected FIR Focus) also shipped and is remembered across visits; a literal "pin a callsign to the top of the live table" is still open and stays on the backlog.
- [x] Deprecation & Cleanup: Migrated off the deprecated `st.components.v1.html` before its removal, replaced raw Python function names in loading spinners with plain-English messages, and made empty-result messages explain themselves instead of showing a generic line.
